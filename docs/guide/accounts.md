# 账号与链接

## 为什么要分账号

每个机器人、脚本或服务器可以使用独立账号。这样能够单独停用某个调用方，也能分别查看请求数量、成功率、流量和耗时。

![账号管理](/images/accounts.jpg)

## 创建账号

1. 进入 **账号** 页面。
2. 点击 **添加账号**。
3. 填写账号名称、代理用户名和代理密码。
4. 保持“启用账号”开启。
5. 点击底部 **保存账号**。

账号名称只用于 WebUI 展示；真正连接代理时使用的是代理用户名和代理密码。

## 复制链接

进入 **链接** 页面，找到对应账号后点击复制：

```text
http://用户名:密码@代理服务器:17891
```

![代理链接](/images/links.jpg)

页面默认遮挡密码，点击复制时写入剪贴板的是完整链接。

## 查看单账号数据

点击账号卡片下方的 **查看数据**，可以查看今日与累计：

- 代理请求与成功请求；
- 失败和白名单拦截；
- 上下行及总流量；
- 平均耗时与成功率。

## 停用或删除

- 关闭“启用账号”后保存，该账号会立即失去代理权限。
- 删除账号需要确认并保存后才生效。
- 多个浏览器同时编辑账号时，旧页面会被拒绝保存，避免覆盖较新的配置。
