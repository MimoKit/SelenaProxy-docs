# 常见问题

## 返回 407

检查代理用户名和密码是否正确、账号是否已启用。没有任何启用账号时也会返回 `407`。

## 返回 403

目标域名或目标端口不在白名单。进入 **设置** 检查“允许域名”和“允许端口”。

## 返回 502

通常表示没有可用节点、供应商提取失败，或者短效代理无法连接目标。打开 **日志** 查看具体原因。

## WebUI 无法打开

依次检查：

1. SelenaProxy 进程或容器是否运行；
2. `status.host` 是否监听 `0.0.0.0`；
3. 防火墙是否放行 `17892`；
4. 服务器安全组是否允许访问；
5. 日志中是否有监听端口失败。

## 复制链接中的地址不对

进入 **设置**，把“对外访问地址”改成调用方能够访问的服务器 IP 或域名。不要填写 `http://`、端口或路径。

## 忘记管理员密码

管理员凭据保存在运行数据目录的 SQLite 数据库中。目前没有网页重置入口。请先备份数据，再重新初始化运行目录。

## Docker 修改本地 config.yaml 没生效

首次启动后，实际运行配置保存在 `selena-proxy-data` 卷中，并由 WebUI 修改。主机上的 `config.yaml` 主要用于首次创建数据卷配置。

## Windows 编译提示 link.exe not found

安装 Visual Studio Build Tools 2022，并选择 **使用 C++ 的桌面开发**。安装后重新打开 PowerShell，再运行：

```powershell
cargo build --release --locked
```
