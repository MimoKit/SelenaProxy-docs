# 运行配置

![运行设置](/images/settings.jpg)

## 供应商

| 配置 | 作用 | 建议 |
| --- | --- | --- |
| 多米 API 地址 | 提取短效代理的完整接口 | 使用 WebUI 密码框保存 |
| 最短提取间隔 | 两次供应商请求之间的最短等待 | 按供应商限制设置 |
| 单次提取数量 | 一次补充多少节点 | 普通使用填 `1` |
| 供应商单次上限 | 限制一次请求的最大数量 | 不超过供应商套餐限制 |
| 请求超时 | 等待供应商响应的时间 | 一般 `10` 秒 |

## 节点策略

| 配置 | 作用 |
| --- | --- |
| 保守存活时间 | API 没有返回到期时间时使用的默认寿命 |
| 到期安全余量 | 提前停止分配即将过期的节点 |
| 最大失败次数 | 节点连续失败多少次后移除 |
| 单节点最大并发 | 一个短效代理最多同时承载多少条连接 |

保守存活时间必须大于到期安全余量。短效代理寿命不确定时，可以先使用默认值，再根据日志调整。

## 代理入口

| 配置 | 作用 |
| --- | --- |
| 监听地址 | SelenaProxy 在本机监听的地址 |
| 监听端口 | HTTP CONNECT 代理端口，默认 `17891` |
| 对外访问地址 | 生成复制链接时使用的 IP 或域名 |
| 连接超时 | 连接短效代理及目标接口的等待时间 |
| 隧道空闲超时 | 双向都没有数据时多久关闭连接 |
| 最大轮换次数 | 一次请求最多尝试多少个短效节点 |

## 白名单

允许端口和允许域名同时生效。例如：

```yaml
allowed_ports: [443]
allowed_hosts:
  - "api.kurobbs.com"
  - "*.aki-game2.com"
```

`*.example.com` 可以匹配 `api.example.com`，不会匹配根域名 `example.com`。

::: danger
不要为了省事开放不需要的域名和端口。白名单越小，代理被误用的范围越小。
:::
