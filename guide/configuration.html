供应商 ​

配置作用建议
多米 API 地址提取短效代理的完整接口使用 WebUI 密码框保存
最短提取间隔两次供应商请求之间的最短等待按供应商限制设置
单次提取数量一次补充多少节点普通使用填 1
供应商单次上限限制一次请求的最大数量不超过供应商套餐限制
请求超时等待供应商响应的时间一般 10 秒

节点策略 ​

配置作用
保守存活时间API 没有返回到期时间时使用的默认寿命
到期安全余量提前停止分配即将过期的节点
最大失败次数节点连续失败多少次后移除
单节点最大并发一个短效代理最多同时承载多少条连接

保守存活时间必须大于到期安全余量。短效代理寿命不确定时，可以先使用默认值，再根据日志调整。

代理入口 ​

配置作用
监听地址SelenaProxy 在本机监听的地址
监听端口HTTP CONNECT 代理端口，默认 17891
对外访问地址生成复制链接时使用的 IP 或域名
连接超时连接短效代理及目标接口的等待时间
隧道空闲超时双向都没有数据时多久关闭连接
最大轮换次数一次请求最多尝试多少个短效节点

白名单 ​

允许端口和允许域名同时生效。例如：

yaml
allowed_ports: [443]
allowed_hosts:
  - "api.kurobbs.com"
  - "*.aki-game2.com"
1
2
3
4

*.example.com 可以匹配 api.example.com，不会匹配根域名 example.com。

DANGER

不要为了省事开放不需要的域名和端口。白名单越小，代理被误用的范围越小。
